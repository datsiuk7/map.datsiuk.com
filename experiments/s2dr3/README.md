# Проба S2DR3 для Києва

Підготовлено 31.10.2026. Обробку ще не запущено: потрібен вхід у Google
Colab і Gamma Earth та власний ключ Gamma Earth.

На карті є кнопка **«API-ключі»** для власного ключа Gamma Earth і перевірки
балансу без запуску завдань. Цей ключ не передається автоматично в Colab:
для безкоштовної проби його потрібно окремо додати в Secrets блокнота.

Параметри проби:

- Центр: 30.523404° E, 50.450099° N (центр Києва).
- Ділянка: 4 × 4 км; це стандартна площа функції демо `inferutils.test`.
- Цільова дата: 2026-10-31. Сервіс вибирає найменш хмарний знімок у періоді
  перед цією датою. Фактичну дату потрібно брати з результату, а не з цього параметра.
- Модель: офіційний `s2dr3-20261012.1` для Python 3.13 / Linux.
- Середовище: Google Colab, GPU T4. На локальний Windows модель не встановлюється.

## Запуск

1. Увійти або створити акаунт на https://app.gamma.earth/.
   Підтвердження умов сервісу власник акаунта виконує особисто.
2. У Gamma Earth скопіювати власний активний ключ на сторінці
   **API Access & Keys**. Не додавати його у файли сайту чи публічні блокноти.
3. У Google Colab відкрити **File → Upload notebook** та завантажити
   [kyiv-trial.ipynb](kyiv-trial.ipynb).
4. Вибрати **Runtime → Change runtime type → T4 GPU**.
5. У розділі **Secrets** створити секрет `GE_API_KEY` зі своїм ключем і дозволити
   доступ цьому блокноту. Значення ключа не друкується й не включається в експорт.
6. Виконати клітинки по черзі. Клітинка обробки запускає одне завдання S2DR3.
7. Відкрити посилання попереднього перегляду, яке поверне модель, і перевірити
   чіткість, фактичну дату та прив'язку. Остання клітинка завантажує ZIP із
   поліпшеними RGB GeoTIFF та описом запиту.

Base Plan зараз має 75 безкоштовних кредитів на місяць для Colab / QGIS.
Україна належить до Region C: один кредит покриває 2 км²; ця проба 16 км²
орієнтовно потребує 8 кредитів. Потрібно перевірити баланс перед запуском.
Автоматичний REST API та Python SDK поза цим демо вимагають платного плану.
Платні пакети, підписки або поповнення в цій пробі не оформлюються.

## Перевірка перед додаванням у карту

S2DR3 створює зображення з кроком 1 м/піксель за допомогою ШІ. Це не
гарантує реальної метрової точності об'єктів: можливі спотворення будівель
і дрібних деталей. Поліпшений кадр слід порівняти з оригіналом тієї самої
сцени; Esri / MapTiler можуть містити кадри іншої дати.

Після проби потрібні фактичні GeoTIFF, дата зйомки, межі й перевірка
умов публікації. Для Leaflet RGB GeoTIFF можна перетворити на XYZ-тайли
в Web Mercator і додати окреме джерело **Sentinel-2 AI · S2DR3** лише з
дійсно обробленими датами. Поки результату немає, це джерело не додається
до списків як начебто доступна карта.

Офіційний блокнот містить ліцензійну примітку: програму надано для тестування,
оцінки та валідації; для розширеного й комерційного використання слід звертатися
до Gamma Earth. Умови розповсюдження результатів на публічному сайті ще
не підтверджено. Безкоштовні результати можуть мати публічні прев'ю.
