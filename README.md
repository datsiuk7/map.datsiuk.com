# map.datsiuk.com

Статична карта для порівняння супутникових знімків або перегляду одного кадру.
Для кожної половини окремо вибираються провайдер, рік, місяць і доступна дата.
Джерело також відображається сірим підписом у дужках поруч із датою.

Стрілки під датою перемикають попередній / наступний доступний знімок
вибраного провайдера. Вони проходять через межі місяців і років, автоматично
оновлюючи фільтри; на краях архіву відповідна стрілка вимикається.

Галочка **«Одна карта»** розгортає ліву карту на всю ширину, прибирає праву
панель і розділювач. Праві зображення та підписи в цьому режимі вивантажуються
і не запитуються знову, доки не повернути порівняння. Вибір правої карти
зберігається. Провайдери, дати й режим записуються в посилання; старі посилання
без провайдерів підтримуються.

## Чітке фото та історія

Кнопка **«📷 Чітке фото»** збирає видиму ділянку карти з тайлів найглибшого
рівня, який реально має провайдер. Карта на екрані обмежена рівнем 18, а
«Наближення» лише розтягує його. Фото натомість бере:

- Esri — поточна карта: до z21; наявність рівнів перевіряється через Esri
  tilemap (Київ — z19, Нью-Йорк — z20). Тайли без даних беруться з батьківського рівня.
- Esri Wayback і Clarity: z19, якщо реліз його має. Перед збиранням
  перевіряється центральний тайл; без нього рівень знижується, а не розтягується.
- MapTiler / Mapbox: рівень з їхнього TileJSON (до 19). Landsat: z12 (30 м).

Найкраще наблизити потрібне місце (зокрема повзунком «Наближення») і натиснути
кнопку: що менша видима ділянка, то глибший рівень вміщується в ліміт 16 Мп.
У режимі порівняння створюються два фото. Повторне натискання скасовує збирання.
Унизу фото друкується атрибуція джерела.

**«Історія»** зберігає фото в IndexedDB цього браузера (до 60 фото й 400 МБ,
найстаріші видаляються першими). Тут можна переглянути фото у 100 %,
завантажити JPEG, повернути карту на місце фото й видалити записи.
URL тайлів не зберігаються, тому ключі MapTiler / Mapbox в історію не потрапляють.

**ШІ ×2 / ×4** — необов'язкове збільшення моделлю ESRGAN (UpscalerJS 1.0.0,
TensorFlow.js 4.11.0, з jsDelivr із SRI). Модель (~3 МБ) завантажується лише
при першому натисканні й працює локально у браузері через WebGL. Результат
зберігається окремим записом із позначкою «деталі домальовано»: мережа
вигадує правдоподібні деталі й не відновлює те, чого не зняв супутник.
Вихід обмежено 12 Мп.

## Запуск

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Відкрити http://127.0.0.1:8080/. Потрібен HTTP-сервер: ES-модулі не слід
відкривати подвійним клацанням через `file://`.
Збірка, база даних, PHP та npm-залежності не потрібні. Esri й Landsat
працюють без ключів; MapTiler і Mapbox використовують власні ключі відвідувача.

## Власні API-ключі

Кнопка **«API-ключі»** відкриває налаштування MapTiler, Mapbox і Gamma Earth.
Для кожного сервісу є поле ключа, показ / приховування, посилання на кабінет
і перевірка підключення. Mapbox приймає лише публічні токени `pk.`; секретні
`sk.` відхиляються до мережевого запиту.

За замовчуванням ключі залишаються в `sessionStorage` цієї вкладки й переживають
перезавантаження. Галочка **«Запам’ятати на цьому пристрої»** явно дозволяє
збереження в `localStorage`; без неї постійна копія видаляється. Кнопка
**«Видалити всі ключі»** очищає обидва сховища, скидає перевірки й прибирає
шари, що використовували видалені ключі. Якщо браузер заблокував сховища,
ключі працюють у пам'яті сторінки, а користувач бачить фактичний режим.

Спільних ключів власника немає. `assets/imagery-config.js` залишено порожнім
для старих кешованих збірок; робочий код його не використовує.
Ключі не потрапляють до URL сторінки, посилань «Поділитися», логів застосунку
чи на сервер сайту. Запити йдуть безпосередньо офіційному провайдеру.
При ввімкненому запам'ятовуванні ключі зберігаються в браузері без шифрування;
опція призначена для особистого пристрою. Браузер також має власний кеш
мережевих запитів, незалежний від сховищ застосунку.

Позначка **🔑** означає, що відвідувач має додати ключ. Відсутність ключа
не позначає провайдера як недоступного. **❌** з'являється після справжньої
помилки підключення з ключем. Заміна ключа скидає попередній статус провайдера.

Перевірка MapTiler / Mapbox запитує метадані та один тайл (HEAD, із GET лише
якщо HEAD не підтримано). Gamma Earth використовує тільки `GET /jobs/{key}`
для читання балансу; `POST` і платна обробка не виконуються. Це налаштування
доступу, не готовий оброблений шар S2DR3. У формі є інструкція безкоштовної
проби в Colab і завантаження підготовленого блокнота. Ключ у Colab відвідувач
додає окремо як секрет `GE_API_KEY`.

## Швидкодія

- Leaflet 1.9.4 постачається локально в `assets/vendor/`, з оригінальною
  ліцензією. SHA-256 JavaScript і CSS перевірено за початковими SRI-хешами.
- Каталоги Landsat запитуються для невеликої комірки карти.
  Переміщення всередині неї використовує ті самі дані; геометрія кожної сцени
  перевіряється для фактичного центру, щоб не пропонувати кадри без покриття.
- Кеш каталогів: до 16 записів, 20 хвилин; метадані: до 128 записів, 24 години.
  IndexedDB зберігає їх між відкриттями сторінки; без доступного сховища
  залишається кеш у пам’яті. Однакові паралельні запити об’єднуються.
- Метадані з ключами MapTiler / Mapbox зберігаються лише в пам'яті, до 8 записів
  на годину. Заміна ключа скасовує старі запити й очищає їхні метадані. Старі
  записи з ключами попередніх версій видаляються з IndexedDB при відкритті.
- Кнопка «Повторити» оновлює каталоги примусово. Помилки й незавершені
  завантаження в кеш не записуються.
- Стрілки об’єднують швидкі послідовні натискання. Поки новий кадр
  завантажується, попередній лишається видимим і його дата зазначена внизу.
  Невдалий новий кадр не прибирає успішно показаний попередній.
- Після показу кадру готуються лише метадані двох сусідніх дат; зображення
  наперед не завантажуються. Заощадження трафіку та повільне з’єднання
  вимикають цю підготовку.
- Розділювач і синхронізація карт оновлюються через animation frame;
  запис URL та оновлення каталогу не виконуються на кожну подію руху.
- Apache за наявності `mod_deflate` стискає текстові ресурси. Версійовані
  файли Leaflet отримують довгий кеш браузера. Копії зовнішніх знімків
  для офлайн-використання не створюються.

## Джерела

Недоступні провайдери позначаються **❌** в обох списках. Позначка базується
на останній помилці каталогу, зображення або легкої перевірки підкладки,
зберігається у браузері до 15 хвилин і знімається після успішного відновлення.
Успішне завантаження каталогу саме по собі не приховує помилку знімків.
Провайдера з хрестиком можна вибрати повторно; причина доступна в підказці.
Перевірка доступності не завантажує повні часові архіви чи зайві зображення.

Меню розділяє **детальні підкладки**, **детальний архів Esri за датами** та
**оглядові знімки Landsat**. Їхню реальну деталізацію не можна
підвищити звичайним збільшенням карти.

### Детальні підкладки

- **MapTiler Satellite** — використовує власний ключ відвідувача з налаштувань.
  Фактичний TileJSON: `https://api.maptiler.com/tiles/satellite-v2/tiles.json`.
  При перевірці API повернув Satellite, масштаб 0–22 і JPEG-тайли;
  київський тайл на z17 віддав HTTP 200.
  Старий `satellite` (Satellite v1) навмисно не використовується через
  гіршу деталізацію. Джерело вибору v2:
  https://www.maptiler.com/news/2023/10/global-high-resolution-satellite-map/ .
- **Mapbox Satellite** — використовує власний публічний токен відвідувача
  через офіційні TileJSON/Raster Tiles API. Офіційний сервер
  `api.mapbox.com` використовується замість старих `a.tiles.mapbox.com`.
  Перед завантаженням повного екрану перевіряється доступ одним HEAD-запитом;
  відповіді 401/402/403/429 показуються як зрозуміле повідомлення. При
  помилці попередній успішний кадр залишається видимим.
- **Esri — поточна карта** — без ключа,
  `https://services.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer`.
- **Esri Clarity — архів** — без ключа, добірка архівних кадрів для чіткості,
  `https://clarity.maptiles.arcgis.com/arcgis/rest/services/World_Imagery/MapServer`.
  Сервіс не оновлюється з 2022 року. Esri запланувала його закриття на
  **березень 2028**: https://www.esri.com/arcgis-blog/products/arcgis-living-atlas/announcements/sunsetting-legacy-basemaps .

Ці чотири джерела є мозаїками різних дат: рік, місяць і стрілки для них
приховані; замість вигаданої дати показується «Поточне покриття» або
«Архів Clarity». Якість і свіжість залежать від конкретної ділянки.
Справжня просторова деталізація не виводиться з масштабу тайлів.

Для продакшну клієнтські ключі можна обмежити доменами сайту в консолях сервісів.
Логотипи взяті без змін з офіційних ресурсів MapTiler/Mapbox; attribution
показується для фактично відображуваних джерел.

### Архіви за датами

- **Esri World Imagery Wayback**: каталог версій із 2014 року, автоматичне
  оновлення й пошук місцевих змін через Esri tilemap. Резервний каталог містить
  198 версій, перевірених 31.10.2026; найновіша — 29.10.2026.
  Дата Esri означає публікацію базової карти, а не зйомку місцевості.
- **Landsat Collection 2 Level-2**: RGB, 30 м/піксель, каталог із 1982 року.
  Фактична найдавніша дата залежить від місця. Для центру Києва під час
  перевірки була доступна 07.04.1984.
- Landsat шукається через публічний STAC Microsoft Planetary
  Computer й відображаються його TileJSON/XYZ-сервісом. Повна пагінація
  охоплює старі та нові сцени. Доступ залежить від зовнішніх сервісів.
- Пошук населених пунктів — Nominatim / OpenStreetMap.

Сцени добираються за **центром карти**, з хмарністю **до 30% для всієї сцени**.
Це не гарантує відсутності хмар саме над центром. Покриття Landsat
обмежене знятим кадром; поза ним показано нейтральне тло, без підмішування
сучасної карти. Переміщення карти оновлює доступні дати.

Списки дат містять лише знімки вибраного провайдера. На кожну дату показується
один варіант; серед сцен одного джерела перевага меншій хмарності. Точний знімок із
збереженого посилання має пріоритет. Поточний ручний вибір зберігається під
час оновлення списку. Якщо сцена більше не покриває центр карти, обирається
найближча доступна дата цього провайдера. Без збережених параметрів відкривається
поточна детальна Esri. Для архіву Esri початково вибираються найдавніша й
найновіша дати. Старі посилання з датованими знімками підтримуються.
Завантажуються лише каталоги активних провайдерів.

Звичайний Sentinel-2 (10 м/піксель) вилучено зі списків і завантаження.
Старі посилання з `sentinel:` або `leftProvider=sentinel` / `rightProvider=sentinel`
відкривають поточну Esri, не відновлюючи вилучені знімки.

## Проба S2DR3

Блокнот [experiments/s2dr3/kyiv-trial.ipynb](experiments/s2dr3/kyiv-trial.ipynb)
підготовлено для безкоштовної проби Gamma Earth у Google Colab: ділянка
4 × 4 км навколо центру Києва, цільова дата 31.10.2026. Потрібні вхід у
Google і Gamma Earth та секрет Colab `GE_API_KEY`. Ключ не записується в
файли сайту. Власний ключ можна ввести й перевірити у «API-ключі»; запуск
Colab потребує окремого секрету `GE_API_KEY` у його середовищі.
Інструкції й посилання: [experiments/s2dr3/README.md](experiments/s2dr3/README.md).

Оброблений кадр ще не отримано. Джерело S2DR3 з'явиться в карті після
перевірки фактичного результату, його дати, прив'язки й умов публікації.
Дати або зображення для демонстрації не вигадуються.

CORONA та ранній Landsat MSS (1972–1982) не підключені:
для них потрібні окремі підготовлені дані або доступ. У списку немає
демонстраційних чи вигаданих дат.

## Перевірки

За наявності Node.js:

```powershell
npm test
```

Якщо середовище забороняє дочірні процеси, на сучасному Node.js:

```powershell
node --test --test-isolation=none tests/*.test.js
```

Перевірено: пагінацію до давніх сцен, вибір джерела на однакові дати,
відновлення посилань, скасування застарілих запитів, збереження ручного
вибору, межі сцен, некоректні параметри URL й відмови API.

## Публікація

Сайт публікується через **GitHub Pages** з гілки `main`, корінь репозиторію.
Файл `CNAME` задає власний домен `map.datsiuk.com`; адреса
`datsiuk7.github.io/map.datsiuk.com/` автоматично переадресовується на нього.
`.nojekyll` вимикає обробку Jekyll, щоб файли віддавалися як є.

1. GitHub → **Settings → Pages**: Source — *Deploy from a branch*,
   гілка `main`, папка `/ (root)`. Custom domain — `map.datsiuk.com`.
2. У DNS домену `datsiuk.com` додати запис
   `CNAME  map  →  datsiuk7.github.io.`
3. Коли перевірка DNS пройде, увімкнути **Enforce HTTPS**.
4. Після запуску налаштувати редирект зі старого `datsiuk.com/map/` і оновити
   посилання основного сайту за потреби.

GitHub Pages не читає `.htaccess`: його правила потрібні лише на Apache.
Referrer-Policy задано також через `<meta name="referrer">` в `index.html`.
Pages віддає всі файли з `Cache-Control: max-age=600`, тому версії `?v=`
у `index.html` слід оновлювати при кожній зміні ресурсів.

Якщо хостинг задає CSP, дозволити власні статичні файли, а також
`s3-us-west-2.amazonaws.com`, `wayback.maptiles.arcgis.com`,
